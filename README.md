# Hongyi Xu — Academic Website

Source for [hongyix99.github.io](https://hongyix99.github.io/).

A static academic homepage with a profile sidebar, biography, the current working paper, education, and teaching. Research interests appear only in the biography. The layout follows the compact academic style of [Yicheng Teng's website](https://yicheng-teng.github.io/); the implementation and personal content are original.

## Files

- `index.html`: public content, links, and metadata.
- `styles.css`: responsive layout, typography, print styles, and both color themes.
- `script.js`: optional theme preference and footer year.

No build or dependencies are required. GitHub Pages publishes from the root of the `main` branch. Open `index.html` locally to preview it.

## Updating content

Edit the corresponding section in `index.html`. Add publications or talks only when their titles, author lists, status, and links are confirmed. The current paper is labeled as a working paper in preparation; the title is provisional and no submission or acceptance is claimed.

The biography, education, and experience were reconciled with the current academic CV on October 1, 2026. No CV download or portrait is linked until a public version is supplied; the sidebar uses the owner's initials.
